# SocioBosques—Ecuador
**“Ecopayments’ Deforestation Impacts on Highly Intervened Frontiers: Extending Ecuador’s Evidence in Light of Amazon Policy Interactions”**

## Abstract

This study examines the forest impacts of Ecuador’s SocioBosque (SB) ecopayments program in Amazonian frontiers. We assess whether SB’s effects differ when the program overlaps with Protected Areas (PAs) and Indigenous Lands (ILs), considering four policy configurations:

1. SB alone
2. SB + PA
3. SB + IL
4. SB + PA + IL

Using remotely sensed forest data and difference-in-differences estimators, we find evidence of forest impacts for SB Collective contracts implemented alone, with larger but imprecisely estimated effects for SB Individual contracts. We find no additional effect of SB Collective contracts within Protected Areas and no statistically significant additional effects when SB overlaps with Indigenous Lands or with both Protected Areas and Indigenous Lands. These findings suggest substantial conservation-policy redundancy in highly intervened frontiers.
